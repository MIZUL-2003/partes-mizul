MIZUL PARTES DE FRENTE - versión final (5/10/2026)
==================================================

ACTUALIZAR TU APP EN GITHUB
1. Entra a github.com/MIZUL-2003/partes-mizul
2. Add file > Upload files
3. Arrastra TODOS estos archivos:
   index.html, app.js, sw.js, manifest.webmanifest,
   exceljs.min.js, docx.min.js, icon-192.png, icon-512.png, icon-maskable-512.png
4. Commit changes (botón verde).
5. (Opcional) El archivo antiguo xlsx.full.min.js ya no se usa: puedes borrarlo
   (ábrelo en GitHub > ícono de tres puntos > Delete file > Commit changes).

EN EL CELULAR
- Espera 2 minutos, abre la app con internet, ciérrala y ábrela otra vez.
  (La primera vez carga la versión guardada; la segunda, la nueva.)
- Al abrirse por primera vez ya trae tus 8 frentes, las tomas laterales y las 269 partidas.
- Tus partes anteriores NO se borran.

IMPORTANTE
- Los datos viven solo en el celular. Usa "Guardar respaldo" cada semana.
- Para pasar datos a otro celular: "Guardar respaldo" en el viejo y "Restaurar respaldo" en el nuevo.
- En Word: Archivo > Opciones > Avanzadas > marca "No comprimir las imágenes del archivo"
  para que las fotos no pierdan calidad al guardar.
